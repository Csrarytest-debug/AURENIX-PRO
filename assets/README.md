# AURENIX PRO branding

The original, user-approved BS Broadcast logo belongs **only** in the AURENIX PRO background-remover application.

Place the supplied original PNG at `assets/bs_broadcast_logo.png` without recoloring, cropping or redrawing it. The application loads this exact file into its upper-left header. The logo is not shared with other applications.

The source repository does not yet contain the uploaded binary PNG; packaging without it will show a fallback text label and is **not** the approved branded final release.
