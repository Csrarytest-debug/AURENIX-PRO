AURENIX PRO BG Remover V0.7.3 - ISOLATED AI ENGINE / RAM CRASH FIX
2026-11-11

WHAT CHANGED
1. The UI no longer executes AI inference in its own process. On Start, a
   separate OS child process is launched via QProcess. Native CUDA/ONNX crashes
   can kill the AI child without directly terminating the GUI.
2. File-based JSON event and command IPC is compatible with PyInstaller's
   --windowed mode, where sys.stdout and sys.stdin may be unavailable.
3. A parent-side watchdog checks the child RAM every 1.5 seconds and kills the
   child if its resident memory exceeds min(6 GiB, 40% of installed RAM), or
   system free RAM falls below 1 GiB. This is a protective limit, not a
   guarantee against instantaneous out-of-memory failures.
4. Pause, Resume and Stop are sent to the child; Stop forcibly terminates
   the child after eight seconds if it cannot exit gracefully.
5. The AI model loads only after Start Processing. After processing finishes,
   the AI process exits and the operating system reclaims its memory.
6. The UI RAM monitor now differentiates SYSTEM memory percentage from the
   APP's resident memory, to avoid falsely attributing system-wide RAM to the app.
7. Previous image processing, preview, guided wire cleanup, original-image
   preservation, output destination and BS Broadcast UI are retained.
8. GPU build now runs a REAL inference smoke test using the PACKAGED EXE
   before it allows Inno Setup to create an installer. It refuses to call
   a provider-only check proof of successful inference.
