NOT VALIDATED HERE

IMPORTANT
This ZIP is source code and build scripts, NOT a compiled Windows EXE.
No ONNX model weights are included in this ZIP. The GPU Windows build pipeline
fetches them during build, then requires they be bundled before installer
creation. The Windows build environment needs Python 3.12, internet for its
one-time dependency/model setup, and Inno Setup 6 for the Setup EXE.

Guided Wire Mask is NOT automatic wire detection. It can alter surrounding
pixels; inspect edited results before saving.

No files on the user's Windows D: drive have been accessed or changed.
